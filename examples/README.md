# Example projects

Small projects created with the stack and kickoff skill. Each README explains how to run the project and what remains to be built.

| Project | What's included |
| --- | --- |
| [RateCraft](04-ratecraft/README.md) | A SolidStart rate calculator that runs in the browser |
| [FieldStock](05-fieldstock/README.md) | A SolidStart app shell with a Rust health API and generated OpenAPI client |

Copy a project into a new directory and follow its README. FieldStock's API requires Rust.
